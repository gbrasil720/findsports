# 02: Administrar sessões da conta

**What to build:** Permitir que torcedores e responsáveis por bares identifiquem a sessão atual, consultem os demais acessos e encerrem uma sessão específica ou todas as outras, com retorno claro sobre o resultado.

**Blocked by:** 01: Entregar configurações básicas nas duas experiências.

**Status:** done

- [x] A sessão atual aparece destacada e sua saída usa a ação comum de logout.
- [x] Outras sessões exibem IP, última atividade, expiração e user agent secundário sem heurística de dispositivo.
- [x] É possível revogar uma sessão específica e todas as outras, atualizando a lista após sucesso.
- [x] A interface distingue sessão de dispositivo confiável e anuncia carregamento, vazio, sucesso e erro.
